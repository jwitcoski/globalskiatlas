Vector preview (PMTiles + MapLibre) A raw .mbtiles URL cannot be drawn in the browser like this. Host a .pmtiles copy (same data, single-file + HTTP Range). Convert locally, then upload next to your mbtiles, or paste a .pmtiles URL below. Your bucket must allow CORS with GET and Range.
How this tileset was built (step-by-step)

From the globalskiatlas_data repo root. Docker Desktop must be running for steps 2–3.

  1. Parquet → GeoJSON. Tippecanoe reads GeoJSON, not Parquet. 
    py -3 scripts/export_combined_to_geojson.py -i output/combined -o output/tippecanoe_geojson
    Writes lifts.geojson, pistes.geojson, ski_areas.geojson (and optional others) into output/tippecanoe_geojson/.
  2. GeoJSON → MBTiles (Tippecanoe in Docker). The container has a Linux Tippecanoe binary; -v mounts your host folder so inputs and ski_combined.mbtiles live on disk. Pull once: docker pull morlov/tippecanoe:latest 
    docker run --rm -v "C:/path/to/globalskiatlas_data/output/tippecanoe_geojson:/data" --entrypoint tippecanoe morlov/tippecanoe:latest -f -zg -o /data/ski_combined.mbtiles --drop-densest-as-needed --extend-zooms-if-still-dropping /data/lifts.geojson /data/pistes.geojson /data/ski_areas.geojson
    Replace C:/path/to/globalskiatlas_data with your clone path. Layers in the MBTiles: lifts, pistes, ski_areas.
  3. MBTiles → PMTiles (Protomaps go-pmtiles in Docker). Same folder mount; this repackages the SQLite MBTiles archive into a single PMTiles file for HTTP Range requests in the browser. Pull once: docker pull ghcr.io/protomaps/go-pmtiles:v1.30.1 
    docker run --rm -v "C:/path/to/globalskiatlas_data/output/tippecanoe_geojson:/data" ghcr.io/protomaps/go-pmtiles:v1.30.1 convert /data/ski_combined.mbtiles /data/ski_combined.pmtiles
    Produces output/tippecanoe_geojson/ski_combined.pmtiles. You do not need to keep both formats forever; MBTiles is the usual Tippecanoe output, PMTiles is for static hosting + this map.
  4. Upload and permissions. Upload ski_combined.pmtiles to HTTPS storage (e.g. S3). The map preview needs a public GetObject (or CloudFront) on that object, plus CORS that allows GET/HEAD and exposes Range-related headers. Then paste that URL above or use the default.
403 Forbidden from S3?

The pipeline bucket is usually private, so anonymous browser requests get 403. Fix one of: (1) bucket policy allowing s3:GetObject on arn:aws:s3:::globalskiatlas-backend-k8s-output/tippecanoe_geojson/* for "Principal":"*", after adjusting “Block public access” so that policy is allowed; (2) a CloudFront distribution in front of the bucket with public read; or (3) for local dev only, run py -3 -m http.server in the folder that contains ski_combined.pmtiles and set the URL to http://127.0.0.1:PORT/ski_combined.pmtiles.
