Vector preview (Planetiler PMTiles + MapLibre) Two tilesets: ski_overview.pmtiles (world → z14) and ski_resort_detail.pmtiles (z12–15 resort context). Requires CORS with GET and Range on S3.
How this tileset was built

From the globalskiatlas_data repo root:

python scripts/build_pmtiles.py

Produces:

  • output/pmtiles/ski_overview.pmtiles — ski_areas_analyzed (z0), ski_areas (z8), pistes + lifts (z10)
  • output/pmtiles/ski_resort_detail.pmtiles — buffer + osm (z12), contours (z13)

Upload to s3://globalskiatlas-backend-k8s-output/pmtiles/ (public read + CORS).

403 Forbidden from S3?

Allow s3:GetObject on arn:aws:s3:::globalskiatlas-backend-k8s-output/pmtiles/*, or use CloudFront. For local dev: py -3 -m http.server in the folder with the .pmtiles files.
