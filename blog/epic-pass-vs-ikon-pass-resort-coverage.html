Epic Pass vs Ikon Pass: What Our Database Actually Covers

August 30, 2026 · 10 min read

Pass tags from pass-affiliations.json against thousands of downhill rows with no pass at all.

Pass coverage in this atlas is data/pass-affiliations.json, matched onto winter_sports_id from the Storm Skiing 2026–27 workbook. It is not Vail’s marketing list and not Alterra’s. This page counts those tags: Indy, Epic, Ikon, plus a leftover “other.” The downhill file still has 3,035 rows. Most of them have no pass in that JSON. The map is Colorado, where destination brands cluster and independents still fill the gaps.

Colorado points. Pass logos do not cover the whole state.

Step 1. The matched counts

Bars update from the JSON when this page loads: 0 Indy, 0 Epic, 0 Ikon. A hill can carry more than one tag. The workbook is a human match, so names like Les 3 Vallées sit on The 3 Valleys (id 45117869) when the matcher found them. If a partner is missing, the row is unlabeled here even if the pass site lists it.

Tags in pass-affiliations.json.

Step 2. Indy is a different inventory

Montage is tagged indy. That is the local-hill product: one mountain, a weekend, no destination village required. Epic and Ikon spend their maps on bigger polygons. If your drive is Scranton, the Indy tag is the one that matters. If your drive is Denver, read both, then still look at the unlabeled dots.

Montage. Indy in the workbook match.

Step 3. Mega domains and pass brands

The 3 Valleys is in the affiliations file. So are other Alpine names the matcher caught. Acre leaders and pass partners overlap, then they do not. Whistler is a North American acre row. Whether a given season’s pass includes it is a workbook question, not an acre question. Check the JSON, not a memory of last year’s brochure.

The 3 Valleys. Huge mapped acres, separate pass tag.

Step 4. The leftover map

Japan still leads country counts. Most of those rows are not on Epic or Ikon. US state bars are the same story at home. Buy a pass if you will use the partners. Count the unlabeled hills if you want the atlas, not the ad.

Downhill rows by country. Pass tags are a thin overlay.
